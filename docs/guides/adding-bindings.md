# Adding Kernel Bindings

`rko-sys` generates bindings automatically through `build.rs`. Configure
and build the kernel first as described in the [README](../../README.md).

## Types, exported functions, and constants

1. Include the defining kernel header in `rko-sys/src/bindings.h` if it is
   not already included transitively.
2. Add its path to the header allowlist in `rko-sys/build.rs`. Dependencies
   of allowlisted types are generated recursively; no partitions or
   injected size/alignment declarations are needed.
3. Run `cargo check --locked`. Access the result directly via
   `rko_sys::name`, or `use rko_sys as bindings`.

Ordinary macros and enums are generated by bindgen. If a complex constant
cannot be evaluated, expose it with an enum in `helpers.h`:

```c
enum { RKO_NAME = KERNEL_MACRO };
```

Functions must be exported by the kernel (check `linux_bin/Module.symvers`)
or supplied by the module's C helpers. A header declaration alone does not
make a kernel symbol available to modules.

## Static inline functions and macros

Add a declaration to `rko-sys/src/helpers.h`:

```c
struct dentry *rust_helper_dget(struct dentry *dentry);
```

Implement it in `rko-sys/src/helpers.c`:

```c
struct dentry *rust_helper_dget(struct dentry *dentry)
{
    return dget(dentry);
}
```

Call `bindings::rust_helper_dget(ptr)` from Rust. CMake rebuilds the shared
helper object and Cargo regenerates its declaration when headers change.
Do not enable binding generation for static functions and then call them
as if they were exported kernel symbols.

## Callback tables

Bindgen exposes C function pointers as typed options:

```rust,ignore
let ops = bindings::file_operations {
    open: Some(open_callback),
    ..Default::default()
};
```

Callback signatures must match the generated parameter and return types
exactly, including pointee types and `usize` sizes.

## Validation

```sh
cargo check --locked
cargo fmt --all -- --check
cargo clippy --locked --all-targets -- -D warnings
cmake --build build --target all
ctest --test-dir build --verbose
```

Bindgen's compile-time layout assertions are enabled. Do not disable them
to work around an ABI mismatch. If an unsupported C representation needs
an opaque type, let clang determine its size/alignment and document the
reason in `build.rs`.
